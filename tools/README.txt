Deployment instructions

1. Replace the repository root index.html with this updated index.html.
2. Upload the four tool HTML files into the repository's /tools/ directory:
   - random-sequence.html
   - dna-sequence-analyzer.html
   - grna-sequence-tools.html
   - sequence-utilities.html
3. Keep the existing index-zh.html and all other files unchanged unless you separately want a Chinese navigation update.

The Tools dropdown is added after Join Us in the existing top navigation. It links directly to the four pages under ./tools/.
Each tool page uses the same visual design language as the supplied homepage and has a Back to Lab Homepage link.
