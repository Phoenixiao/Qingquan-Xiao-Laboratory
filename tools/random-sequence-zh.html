Random Sequence Generator

Generate random DNA or RNA sequences for molecular biology and genetic engineering research.

Generation settings

Allowed range: 1–5,000 nt
Maximum depends on sequence length: 4n unique sequences (subject to browser resource limits).
Optional. When enabled, only sequences whose GC content falls within the inclusive range are returned.

Generated sequences

Each nucleotide is selected independently with equal probability using the browser's Web Crypto random number generator. Generated sequences are random examples, not validated primers or guides.
