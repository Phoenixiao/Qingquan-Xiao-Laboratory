Sequence Alignment

Pairwise global or local alignment of DNA, RNA, and protein sequences using dynamic programming.

1. Input sequences

FASTA headers and whitespace are ignored. DNA–RNA and RNA–DNA comparisons are supported; T and U are treated as equivalent for scoring, while original input characters are retained in the display.

2. Alignment settings

Protein–protein alignment supports both algorithms and the BLOSUM45/50/62/80 and PAM250 matrices. Automatic mode selects BLOSUM62 for proteins and match/mismatch scoring for nucleotides. Mixed DNA/RNA comparisons use nucleotide scoring with T and U considered equivalent.

Consensus / conservation
Consensus uses the identical residue at fully conserved columns; non-identical or gapped columns are shown as X (protein) or N (nucleotide). It is a visualization aid, not a separately inferred biological sequence.

  

 

 
Methodological notes: Needleman–Wunsch performs global alignment; Smith–Waterman performs local alignment. Both are applicable to nucleotide and protein sequences. This implementation uses Gotoh-style three-state dynamic programming for affine gaps. For a gap of length L, the penalty is gap-open + (L−1) × gap-extension. Reported identity is identical aligned residue pairs divided by alignment columns, including columns containing gaps. This is pairwise alignment, not multiple sequence alignment (MSA). Alignment scores depend on the selected matrix and gap parameters; results alone do not establish homology, function, or clinical relevance.
